# Bodybuild Fitness - Premium Gym & Fitness Equipment Website

A high-impact, modern, dark-aesthetic gym and athletic fitness equipment web application built with clean HTML5, CSS3, and JavaScript.

![Bodybuild Fitness Preview](assets/images/hero-workout.jpg)

## ⚡ Features

- **Dark High-Contrast Aesthetic**: Industrial gym styling with pitch-black backgrounds, high-voltage red accents (`#FF2626`), and bold athletic typography.
- **Hero Section**: Eye-catching headline *"GET THE RIGHT GYM FOR YOUR HOME"*, vibrant CTA button, and high-intensity workout photography.
- **Cardio & Studio Gear**: Barbell deadlift athlete visual with custom red chevron graphics (`<<<`) and detailed equipment specs.
- **Featured Equipment Card**: Flagship *"A1 ELLIPTICAL TRAINER"* showcase featuring bulleted inclusions, dual CTA actions, dynamic battle ropes athlete visual, and a floating white price badge ($499.00 / Free Shipping / 30-Day Guarantee).
- **Support Center**: Atmospheric boxing gym ring background with interactive support inquiry modal.
- **Customer Reviews**: 3 high-contrast white testimonial cards with crimson quote badges and athlete reviews.
- **Contact & Footer**: Push-up athlete image banner with giant overlaid *"CONTACT US"* title and 3-column contact details (Email, Phone, Socials).
- **Interactive Modals & Utilities**:
  - Equipment quick-order drawer with finish selector and instant mock checkout.
  - Full product specifications modal.
  - Interactive support request form with live toast notifications.
  - Responsive mobile navigation drawer.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom design tokens, Flexbox & CSS Grid, glassmorphism, micro-animations, and full responsive design.
- **JavaScript (ES6+)**: Modal interactions, cart counter management, active navigation spy, and notification toasts.
- **Fonts**: [Syne](https://fonts.google.com/specimen/Syne), [Archivo Black](https://fonts.google.com/specimen/Archivo+Black), and [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts.

## 🚀 Quick Start

You can run this project locally without any complex installation:

### Option 1: Using Node.js
```bash
node serve.cjs
```
Then visit `http://localhost:8080` in your browser.

### Option 2: Direct Open
Simply double-click `index.html` to open it directly in any modern web browser.
